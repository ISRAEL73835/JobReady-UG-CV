# JobReady UG CV & Application Builder

A mobile-first starter project for creating CVs and job applications.

## Included
- Mobile-friendly CV builder
- Job application mode
- Live preview
- Print / Save as PDF through the phone/browser print dialog
- Save details locally on the device
- English/Luganda/Kiswahili language selector placeholder
- Career guidance chat
- Admin dashboard starter

## Important security note
The admin page is a front-end demo. Do NOT put a real password in public GitHub code. For a real production admin system, authentication must be handled by a secure backend/service and passwords must be stored securely.

## Price
The interface displays UGX 2,500 as the suggested price per generated document. Payment collection is not connected yet.

## Run
Open `index.html` in a browser, or serve the folder from a web host.
